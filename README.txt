TETI TOUR - LOCAL WEBSITE
==========================

Open index.html in your browser.

This version uses local Egypt photos and the local hero video, so the Wikimedia/Unsplash
network-access popup should no longer be triggered by the tour images.

IMPORTANT:
Keep your existing logo.png in this same folder because the website uses it for the Teti Tour logo.

The website still connects to Supabase for prices and to WhatsApp when a customer books.
Those are intentional network connections.

Files:
- index.html
- Teti_Tour_Web_Background_FINAL.mp4
- assets/ (local Egypt photos)
- logo.png (copy your existing logo here)
